About PaperChat

PaperChat is a production-grade RAG (Retrieval-Augmented Generation) system designed for querying arXiv research papers with high accuracy and performance.

Key Features

  • Hybrid Retrieval: Combines BM25 keyword search with semantic vector search for optimal recall
  • CrossEncoder Reranking: Refines results using advanced neural reranking models
  • Multi-Provider LLM: Supports OpenAI, Anthropic, and Google Gemini
  • Citation System: Provides inline numbered citations with deduplicated references
  • Query Optimization: Automatic query expansion and context compression
  • Performance: 2-4 second latency with GPU acceleration

Technology Stack

Backend: FastAPI + Celery
Vector DB: ChromaDB
Embeddings: BGE-large-en-v1.5
Cache: Redis

API Endpoints

POST /api/v1/query Submit a research question
POST /api/v1/ingest Ingest papers from arXiv
GET /api/v1/query/{task_id} Get query results
